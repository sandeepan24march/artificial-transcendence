# ArtificialTranscendence.com

Static landing page designed for free deployment on Cloudflare Pages or GitHub Pages.

## Files
- `index.html` — page content
- `styles.css` — responsive visual design
- `favicon.svg` — site icon
- `robots.txt` — crawler instructions
- `sitemap.xml` — basic sitemap

## Cloudflare Pages
1. Create a GitHub repository and upload these files.
2. In Cloudflare Pages, create a project from the repository.
3. Use the production branch and no build command.
4. Output directory: `/` (the repository root).
5. Add `artificialtranscendence.com` as a custom domain.
6. Point the domain's nameservers to Cloudflare when prompted.
